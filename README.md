## Google Search Console
### Cara Mendaftarkan Website
1. Buka [Google Search Console](https://search.google.com/search-console).
2. Klik **"Add Property"**.
3. Pilih **"URL prefix"** → masukkan URL website Anda.
4. Verifikasi kepemilikan (rekomendasi: HTML file atau DNS).
5. Setelah terverifikasi, submit sitemap:
   - Buka **Sitemaps** di menu kiri.
   - Masukkan `sitemap.xml`.
   - Klik **Submit**.
### Memantau Performa
- Cek **Performance** untuk melihat query pencarian, klik, dan posisi.
- Cek **Coverage** untuk memastikan halaman terindeks.
- Cek **Mobile Usability** untuk masalah tampilan mobile.
